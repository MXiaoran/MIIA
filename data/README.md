# Data directory

Benchmark images, annotations, generated manifests, download caches, and smoke
artifacts are intentionally excluded from Git. Prepare the datasets locally by
following the root `README.md`; the expected layout is created below `data/`.

Do not commit RSICD, RSITMD, UCM-Captions, DALL-E encoder weights, or generated
manifests. Their licenses and redistribution terms are controlled upstream.
